# IMPORTANT: pass the object directly (not .position) to set_pixel_by_radius.
# The function dilates the object's actual occupancy by radius_cm so the
# halo follows the real mesh. Passing .position is supported but for
# perimeter-distributed obstacles (counter, kitchen group) it puts the
# disk at the floor centroid, which is wrong.

ret_val = avoidance_map
